# Native macOS daemon

AgentShell's Rust backend runs natively on Apple Silicon and Intel Macs. It uses
the same Android client, WebSocket protocol, SQLite history and tmux sessions as
the Linux backend. Linux continues to use its existing APT/systemd installer.

## Install

Install Xcode Command Line Tools (`xcode-select --install`) and Homebrew from
[brew.sh](https://brew.sh). AgentShell uses an existing Homebrew installation;
it does not download or execute Homebrew's installer.

```sh
./install.sh --dry-run
./install.sh --check
./install.sh
```

The installer runs as your normal user without sudo. It bootstraps missing
tmux, Rust, Python and OpenSSL prerequisites, builds with Cargo.lock, and creates
a managed Python environment with websockets 13–15. Existing working agent CLIs
are reused. Install Codex, Claude Code or OpenCode separately before using their
features; `--agents none` prepares only the daemon. Existing hooks and MCP
settings are merged and backed up.

The default installation is `~/Library/Application Support/AgentShell`, with
private settings in `backend/runtime.env`, a LaunchAgent in
`~/Library/LaunchAgents/com.agentshell.backend.plist`, and private logs in
`~/Library/Logs/AgentShell`. The existing runtime token is retained on upgrades.
On a fresh installation the token comes from `AUTH_TOKEN` or the checkout's
private `.env`, or is generated once. Values are parsed as literal settings,
never sourced as shell commands, and credentials are kept out of the plist.
Use the same token in the Android client configuration.

```sh
./start.sh status
./start.sh logs
./start.sh restart
./start.sh stop
```

The LaunchAgent starts at login and preserves tmux sessions across daemon
restarts. For an available headless user domain, install with
`--domain user/$(id -u)`. `--no-start` prepares configuration without loading the
agent. `--binary /absolute/path/agentshell-backend` installs a prebuilt binary.
Failed startup restores the previous executable, settings and service file.
Databases and browser profiles remain in their existing locations.

## Build and run from a checkout

```sh
scripts/build-backend.sh
scripts/run-backend.sh
```

The foreground runner reads the checkout's private `.env`, and explicit process
environment values take precedence. `AGENTSHELL_BACKEND_BIN`,
`AGENTSHELL_DATA_DIR` and `AGENTSHELL_ENV_FILE` select another executable,
working directory or settings file. Ports default to HTTP 4010 and HTTPS 4443.
Existing `AGENTSHELL_TLS_CERT_PATH` and `AGENTSHELL_TLS_KEY_PATH` can select a
trusted certificate pair; a missing local pair can be generated by the installer.
Automatic Linux LAN DNS/certbot provisioning remains a separate platform task.

## Native Chrome

The macOS browser provider uses the installed Google Chrome app with a persistent
AgentShell-owned profile. It captures the native Chrome window and routes
authorized input through the macOS helper. It requires macOS 13 or newer.

```sh
./install.sh --with-browser native-macos --browser-origin https://your-trusted-host:4443
```

This option builds `AgentShellBrowser.app`, installs the native runtime, and
keeps its session identity, private access secret and profile across upgrades.
Missing Chrome can be installed through Homebrew when this browser option is
requested. Use an HTTPS origin trusted by your phone.

Grant Screen Recording and Accessibility access to AgentShell Browser when
setting up the helper. Open its permission setup explicitly:

```sh
open "$HOME/Library/Application Support/AgentShell/browser/AgentShellBrowser.app" --args \
  --config "$HOME/Library/Application Support/AgentShell/browser/browser.json" --setup
```

Permission checks report missing access without granting it or capturing a
personal window. Native browser architecture and interaction details accompany
the [native provider implementation](native-macos-browser.md). KasmVNC remains
the Linux browser provider.

## Verification

CI builds and tests on Ubuntu, macOS 15 Apple Silicon and macOS 15 Intel. It runs
the Rust and installer regressions plus an isolated native HTTP/WebSocket/tmux
smoke test, validates matching Python/Rust process generations, exercises PTY
input, and checks session survival across a backend restart. The Swift helper
build and logic tests run on macOS; real screen capture and input require an
interactive Mac with permission granted.

```sh
python3 scripts/test_macos_install.py
python3 scripts/test_backend_install.py
python3 scripts/test_process_identity.py
python3 scripts/test_native_backend_smoke.py --binary backend-rust/target/release/agentshell-backend
```
