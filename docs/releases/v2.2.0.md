# AgentShell v2.2.0

**Native Android 2.2.0 (version code 12) · Rust backend 2.2.0**

This release brings remote Chrome, persistent split views, interactive messages, and offline chat history to AgentShell’s native Android app. The Rust backend now also runs natively on Apple Silicon and Intel Macs.

## Browser and split views

- **Deployment** opens chat and the remote browser together. Choose **Chat options → Deployment** from a conversation, or **Deployment** from the browser toolbar. Stack the panes, place them side by side, resize them, or swap them. The app restores the pairing and layout after Back or an app restart.
- **Remote Chrome** lets you control the host browser from Android, select a Chrome profile, dictate text, and remember the browser content size. On supported Linux desktops you can pass control between phone and computer or open native Chrome. Handoff now recognizes a clean shutdown even when Chrome still has a crash marker from an older run.
- **Chrome windows and tabs** can be managed from **Windows** on Linux with the AgentShell Browser Windows extension. Switch windows, move a live tab to an existing or new window, place two tabs side by side, or preview and merge all tabs into the current window.
- **Chat and terminal** can share a screen for the same tmux window. The split remembers its layout per window. Terminal-only navigation, swipe navigation, and reconnects now select the intended window, including sessions whose first window was deleted.

## Chat, agents, and files

- **Interactive Smart UI cards** bring charts, maps, tables, and controls into chat. Maximize a reply or share a card as an image. Long cards now scroll to their final control, including in maximized messages. System, Light, and Dark themes persist across restarts.
- **Codex** supports direct app-server sessions as well as history and usage from tmux. Native thread IDs keep shared-daemon conversations separate. Direct agent sessions are grouped by project path and provider, and favorites offer a choice of launch target.
- **Offline history** keeps cached sessions and conversations readable when disconnected. Incremental sync resumes after interruption and downloads changed messages. **Battery Saver** reduces background sync and wake time, with an optional timed return to live updates.
- **Activity and alerts** show live agent status, unread markers, and notifications that open the matching chat or alert details. You can now copy an individual reply. Android saves voice recordings before transcription and retries failed requests across app restarts. Dictated messages also submit more reliably.
- **Files** can be uploaded from Android, shared into chat from another app, or delivered by an agent to the linked conversation. Open server files from chat, preview PDFs and interactive HTML, and follow symbolic links in the file browser.
- **Downloads** show progress and can be canceled. The file browser asks before replacing existing files during a copy or move.
- **Delivery and reconnects** preserve conversation bindings, reconcile send receipts with native history, recover stalled confirmations, and keep sent drafts from reappearing. Direct agent file uploads now resolve the session’s working directory.

## Backend and upgrade notes

- The Android Settings screen now shows the installed build’s actual version. Run `agentshell-backend --version` on the host to check the daemon binary.
- The installer can set up backend dependencies, Smart UI tools, and agent integration. macOS uses a per-user LaunchAgent. Its optional native Chrome provider requires macOS 13 or later and Screen Recording and Accessibility permission. Linux remote browsing also requires an optional browser runtime and a trusted HTTPS origin.
- The Android system screen shows live CPU and memory trends and lets you monitor and control Docker and Podman containers. Quick server switching and verified HTTPS discovery support existing LAN bookmarks. A paired computer can discover the phone’s current Wi-Fi debugging endpoint through the backend.
- Backend fixes cover cron editing and startup, notification attachments, slow WebSocket clients, stale tmux tool detection, and repeated launches of failing agents. The terminal bundles its renderer for use without a CDN. Legacy Flutter web startup and proxied CORS configuration also received fixes.
- **Native Android** is the supported Android client. The deprecated Flutter client is still available as a separate download.
- Upgrade the **Android app and backend together** for exact tmux-window targeting and the new browser controls. The Android database migration preserves cached conversations on in-place upgrades.
- The native APK attached to **v2.1.0** has a different signing certificate from this release. Android blocks an in-place upgrade between those two public APKs. To keep local data, build v2.2.0 with your original signing key if you have it. A clean install of the public APK requires setting up the app again, and uninstalling removes its local data.
- Direct Codex sessions run with full filesystem access and approval prompts disabled.
